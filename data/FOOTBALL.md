# Liga MX data and evaluation

The bundled `liga-mx.csv` contains 1,704 regulation results from five completed Liga MX seasons (2020–21 through 2024–25). The source archive also identifies extra-time and penalty outcomes on relevant matches. The conversion retains those scores in separate fields and excludes two awarded games. Match dates in this archive are local calendar dates. To prevent same-day leakage the model makes an archived result available only after two UTC midnights. [OpenFootball source at 42df820](https://github.com/openfootball/world/tree/42df8203e73e922cdfa36104e3acee3aea1f2bc0/north-america/mexico) · [CC0 license](./OPENFOOTBALL-LICENSE.md)

`replay-ratings.json` contains derived team coefficients for the Toluca–Monterrey forecast at 2026-11-07 16:00 UTC. It uses 1,321 matches available before the forecast, including more recent public ESPN regulation results beyond the archive. ESPN results enter the model 24 hours after kickoff. The model fits attack, defense, league intercept, home advantage and a bounded Dixon–Coles low-score correlation by penalized, exponentially time-weighted likelihood. Its training window is four years, with a 365-day half-life and a five-game minimum per team. A new fit uses only the results available by its forecast time. [ESPN fixture](https://www.espn.com/soccer/match/_/gameId/401876905)

After building, `npm run --silent backtest -- --replay-ratings` rebuilds the frozen pre-match ratings from the source scoreboards. The forecast cutoff stays fixed when the command runs later.

With Node 22.18 or later, run `npm ci`, `npm run build`, and `npm run backtest`. The offline backtest refits before each held-out match date in the two 2024–25 tournaments. Its baseline uses the historical frequency of home wins, draws and away wins. Results appear in `backtest-archive.json`.

Run `npm run backtest -- --exchange` for the second evaluation. It downloads public ESPN season scoreboards and historical Kalshi data into `.asterisk-eval-cache`, configurable through `ASTERISK_EVAL_CACHE`. Results in `backtest-exchange.json` cover the exchange-listed, regulation-time subset of Apertura 2025 and Clausura 2026. Quotes are genuine hour-closing yes asks observed two to four hours before kickoff. The evaluation discards unsupported settlement rules, unknown or ambiguous match mappings, and missing quotes. Daily model fits precede the quote cutoff. The combined forecast uses 70% market weight in log-odds space. Results measure predictive accuracy and omit P&L, execution and fees. The market had lower log loss than either model on both samples.

Live fixtures use ESPN’s public Liga MX scoreboard. Availability depends on coverage in that feed. Current starters appear as reported until a confirmation indicator is available. The context includes schedule gaps within Liga MX, scored and conceded goals from confirmed regulation results, and mathematically bounded top-six status for complete 18-club regular-season tables. League rank is null for unresolved tiebreakers. Prior match summaries preserve event minutes, added time, period, player lineups and evidence of a penalty or set piece where supplied. Missing observations remain unknown. ESPN does not supply a complete cross-competition schedule or verified injury/discipline feed here.
